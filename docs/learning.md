# Controlled learning

The learning registry is independent of framework source code. A candidate lesson requires evidence, an originating project, scope, applicability, and confidence. Exact normalized description/scope/applicability duplicates are rejected. Validation checks required metadata; review and promotion are separate steps; promotion always has an explicit user confirmation.

Project-scoped candidates remain visible only to their originating project. A project-less listing returns only globally scoped promoted lessons. Yuntra does not auto-promote lessons or use lessons to rewrite framework code, policies, adapters, or schemas. Evaluation records later evidence about usefulness and limitations.
