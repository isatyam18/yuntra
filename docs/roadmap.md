# Roadmap

## Public beta priorities

- Run CI on pull requests across Windows and Linux.
- Validate installation from a built wheel in a clean environment.
- Gather external feedback on onboarding, checkpoint recovery, and adapter behavior.
- Publish reproducible context-retrieval benchmark inputs and results.

## Next candidates

- Decision-to-code traceability from requirement through change and verification.
- Deterministic handoff completeness scoring.
- Repository relocation recovery.
- Adapter conformance tests against the shared contract.
- Memory integrity checks and crash-safe event processing.
- Learning effectiveness measurement.

## Explicit non-goals for public beta

- Automatic Git commits, pushes, releases, or deployments.
- Cross-project leakage of unpromoted lessons or private state.
- Unsupported claims about provider hooks, edits, or token usage.
- Required hosted services or vector databases.
