# Hello Yuntra example

This fixture illustrates the files and evidence a completed Yuntra-managed project can reference. It contains no executable application and no credentials.

1. Read [PROJECT_SPEC.md](PROJECT_SPEC.md).
2. Review the example [decision record](decision-example.json).
3. Review the example [verification record](verification-example.json).

To create a real project, use `yuntra project create` against your own repository; do not treat this example as canonical state.
